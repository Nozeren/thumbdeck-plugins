# Django

Toolkit buttons for Django projects (with a `manage.py`); the Python plugin comes along.

- **runserver**: `{manage} runserver`. Start the development server (in the tmux window 'server')
- **migrate**: `{manage} migrate`. Apply database migrations
- **makemigrations**: `{manage} makemigrations`. Create migrations from model changes
- **test**: `{manage} test`. Run the test suite
- **shell**: `{manage} shell`. Django shell (interactive, in the tmux window 'shell')
