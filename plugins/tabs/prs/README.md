# Pull requests

The repo's open pull requests that concern you, in a tab, in the order to deal with them:
asked to review again (after you reviewed), asked to review, reviewed by you, and yours. The
highlighted one's details below: checks, labels, comments, reviewers, stale and conflict
flags; a 🔔 marks an unread GitHub notification.

- `l` or `v` opens thumbdeck's review page for its changes (nothing is checked out).
- `o` opens it in the browser and marks its notification read.
- The avatar holds up a sign while PRs wait for your review.

It reads GitHub with the [GitHub CLI](https://cli.github.com) (`gh`), so it uses your gh login.
The repo is the project's `origin` remote, or the one set in the tab's setup (`S`); `demo`
shows sample PRs.
