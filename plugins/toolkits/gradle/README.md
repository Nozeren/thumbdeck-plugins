# Gradle

Toolkit buttons for Gradle projects, mostly Android; the buttons use the project's `./gradlew`.

- **assembleDebug**: `./gradlew assembleDebug`. Build the debug APK (only when it applies)
- **installDebug**: `./gradlew installDebug`. Build and install the debug APK on the connected device (only when it applies)
- **test**: `./gradlew test`. Run the unit tests (only when it applies)
